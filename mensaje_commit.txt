PASO 2 — Fix botones cortados con createPortal (ambos archivos)
═══════════════════════════════════════
Causa raíz identificada:
  El tab "solicitudes" en admin/trabajadores/page.tsx envuelve su
  contenido en un div con `animate-in slide-in-from-bottom-2`, que
  aplica CSS transform: translateY(...) durante la animación.
  En CSS, cuando un ancestro tiene transform, los elementos
  position: fixed pasan a posicionarse relativo a ese elemento
  en vez del viewport — quedando atrapados y cortados por el
  overflow-hidden del mismo contenedor.
  WorkerEditPanel se igualó para garantizar consistencia futura
  ante cualquier contenedor con transform o overflow.

Fix aplicado:
  - ApprovalPanel: import { createPortal } from 'react-dom'
    {isOpen && <> overlay + aside </>}
    → {isOpen && createPortal(<> overlay + aside </>, document.body)}

  - WorkerEditPanel: import { createPortal } from 'react-dom'
    return <> overlay + aside </>
    → return createPortal(<> overlay + aside </>, document.body)

Resultado:
  - Overlay y panel se renderizan directamente en <body>,
    escapando cualquier ancestro con transform u overflow
  - Header fijo: nunca se desplaza ni comprime con el scroll
  - Contenido (flex-1 overflow-y-auto): scroll interno cuando
    el formulario excede la altura disponible
  - Footer fijo: botones siempre visibles en cualquier viewport
  - z-[70] garantiza superposición sobre sidebar y topbar
  - Toda la lógica de negocio (actions, validaciones, estados) intacta
  - Build Next.js pasa sin errores TypeScript
